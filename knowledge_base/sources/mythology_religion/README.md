# Source material — mythology religion

Drop the client-provided source files for this domain here.

Supported formats: `.txt`, `.md`, `.vtt`/`.srt` transcripts, `.pdf` (needs
`pypdf`), `.epub`.

Files in this folder are git-ignored (except this README and the committed
`sample_*.md` demo file) so provided/copyrighted material is never committed.

After adding files, rebuild the index:

    python src/scripts/ingest_knowledge.py
